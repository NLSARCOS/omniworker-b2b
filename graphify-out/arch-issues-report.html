01 / God Nodes CRITICAL
What it means: A god node is an abstraction so heavily referenced that it has become a de-facto dependency of almost everything. Changing it requires touching a massive fraction of the codebase — regression risk is extreme. The top 3 nodes here (Platform, BasePlatformAdapter, PlatformConfig) collectively touch ~4,846 edges, making them the highest-leverage and highest-risk objects in the system.

Why the top 3 are architectural debt: God nodes with 1500+ edges are a sign that interfaces weren't extracted. BasePlatformAdapter at 1582 edges means 20+ platform classes all couple to a single base — adding a new hook to the base is never "safe." Recommended path: extract capability-specific interfaces (Sendable, Subscribable, MediaCapable) that adapters implement selectively.
